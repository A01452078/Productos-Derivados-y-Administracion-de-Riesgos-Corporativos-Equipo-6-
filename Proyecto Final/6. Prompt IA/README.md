# 06 Uso de inteligencia artificial

Documentación del uso de IA en el proyecto, conforme al requisito del curso.

## Archivos
| Archivo | Descripción |
|---|---|
| `Prompt_IA_Walmart.pdf` | Resumen del uso de Claude (Anthropic): rol asignado, prompts, código recibido y registro de correcciones (5 páginas). |

## Criterio de uso
La IA se usó como apoyo para estructurar el análisis y escribir código. Los datos provienen de LSEG Workspace y de los reportes de Walmart, y las cifras se verificaron contra esas fuentes antes de incluirse en los entregables.
